# Customer Data Analysis | Power BI

## Project Overview

This project analyzes customer shopping behavior and sales performance using Microsoft Power BI. The dashboard provides insights into customer demographics, product categories, revenue, and payment preferences.

## Objectives

* Analyze customer shopping behavior by gender and age group.
* Compare revenue across product categories.
* Understand customer payment preferences.
* Identify sales trends and customer purchasing patterns.
* Present key business insights through an interactive dashboard.

## Tools Used

* Microsoft Power BI
* Power Query for data preparation, where applicable

## Key Performance Indicators (KPIs)

* Total Revenue
* Total Orders
* Total Quantity Sold

## Analysis & Dashboard Features

* Gender-wise customer analysis
* Age-group analysis
* Product category revenue comparison
* Payment method analysis
* Shopping mall performance analysis
* Interactive data visualization

## Key Insights

* Clothing is the leading revenue-generating product category.
* Female customers contribute more revenue than male customers.
* The 55–64 age group generates the highest revenue.
* Cash is the most frequently used payment method.

## Business Recommendations

* Develop targeted marketing campaigns for different customer segments.
* Focus on high-performing product categories.
* Analyze payment preferences to improve the shopping experience.
* Use customer purchasing patterns to support inventory and sales planning.

## Conclusion

This project demonstrates how Power BI can transform customer transaction data into meaningful business insights. The analysis supports better understanding of customer behavior and data-driven decision-making.
